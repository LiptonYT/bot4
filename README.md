# ПГО «Каратели» — Склад и снабжение

Discord-бот на Python (discord.py 2.x) с одной основной slash-командой `/warehouse`.

## Возможности
- Единая панель: «Запросить склад», «Отчёт о поставке», «Остатки склада», «Пополнить склад», «История операций».
- Запросы и отчёты получают отдельную сквозную нумерацию: `ЗАПРОС №001`, `ПОСТАВКА №001`.
- Все запросы и отчёты отправляются в канал рассмотрения с упоминанием роли старшего состава.
- Одобрение/отклонение доступно только участникам с ролью старшего состава.
- Одобрение запроса автоматически списывает имущество с общего склада; при нехватке остатка бот не даст одобрить заявку.
- После отправки каждой поставки бот создаёт отдельную ветку для фотоотчёта с её номером. Автор прикрепляет туда реальные фотографии файлами Discord.
- Старший состав проверяет фотографии и заявку; одобрить поставку без хотя бы одного изображения от автора нельзя. Только после одобрения товары поступают на общий склад.
- Одобренная поставка и пополнение старшим составом увеличивают остатки.
- Пополнение склада и полная история доступны только старшему составу.
- SQLite сохраняет остатки, нумерацию, заявки, решения и журнал после перезапуска.
- Автору отправляется личное уведомление о решении (если у него открыты личные сообщения).

## Установка на Bothost / Linux
1. Загрузите содержимое архива в папку бота.
2. Установите Python 3.10 или новее.
3. Установите зависимости: `pip install -r requirements.txt`.
4. Скопируйте `.env.example` в `.env`.
5. В `.env` заполните `DISCORD_TOKEN`, `REVIEW_CHANNEL_ID`, `AUDIT_CHANNEL_ID` и при желании `GUILD_ID`.
6. Роль старшего состава уже указана: `1570353093495881740`. При необходимости измените ID.
7. Включите у бота в Discord Developer Portal привилегированный Gateway Intent **Server Members Intent**.
8. Пригласите бота с правами `bot` и `applications.commands`; на сервере ему нужны права просмотра каналов, отправки сообщений, встраивания ссылок и использования внешних эмодзи (последнее необязательно).
9. Запустите: `python bot.py`.
10. В Discord выполните `/warehouse` от имени участника со старшей ролью. Бот опубликует панель.
11. Для веток фотоотчёта боту нужны права **Create Public Threads**, **Send Messages in Threads** и **Read Message History**. Старшему составу также нужен доступ к каналу рассмотрения.

## Важно
- Не публикуйте `.env` и токен бота.
- `REVIEW_CHANNEL_ID` — канал, где старший состав рассматривает запросы и отчёты.
- `AUDIT_CHANNEL_ID` — канал, куда дублируются события склада. Для одного канала укажите одинаковый ID.
- Вложения напрямую в Discord-модальное окно добавить нельзя, поэтому после отправки отчёта бот автоматически создаёт отдельную ветку с номером поставки. Автор прикрепляет фотографии туда обычными вложениями Discord; бот проверяет наличие фото от автора перед одобрением.
- Первый запуск создаёт `warehouse.sqlite3`. Не удаляйте этот файл, иначе потеряются остатки и история.
- Бот не создаёт стартовые остатки автоматически: склад наполняется через кнопку «Пополнить склад» старшим составом.
